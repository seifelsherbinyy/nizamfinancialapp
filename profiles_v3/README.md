# NIZAM Aki profiles

These profiles use the Aki `profiles_v3` manifest schema and can be imported as a profile folder set.

Import or copy the three profile directories into the Aki profiles directory:

- `nizam-builder` — implementation, tests, and bounded offline development
- `nizam-verifier` — acceptance, invariants, gates, and release-readiness audits
- `nizam-architect` — requirements, contracts, specifications, ADRs, and implementation planning
