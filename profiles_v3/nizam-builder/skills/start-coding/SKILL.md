I need to implement a NIZAM change.

1. Clarify the outcome and identify the applicable contract/spec.
2. Search the repository for at least three relevant implementation or test patterns.
3. Find the exact files and smallest safe change surface.
4. Plan the implementation and tests in 3-5 bullets.
5. Implement with existing conventions and no gold-plating.
6. Verify with focused checks and the full acceptance harness when ready.
